# Recurrence expansion (spec)

`expand(dtstart, rule, after, before, exdates=()) -> list[datetime]`

* `dtstart`: aware datetime whose tzinfo is a `ZoneInfo` (the event zone).
  `rule`: the dict from `parse_rrule`. `after`, `before`, `exdates`: aware
  datetimes in any zone. Returns the occurrences `t` with `after <= t <
  before`, sorted, each as an aware datetime in UTC.
* Every occurrence has dtstart's local wall-clock time (hour, minute,
  second) on its own local date in the event zone. If that wall time does
  not exist on a date (clocks jump forward), the occurrence is shifted
  forward by the length of the jump; if it exists twice (clocks fall back),
  the first one is used.
* Candidates are generated by the rule and are kept only if they are at or
  after dtstart. dtstart itself is an occurrence only if it matches the rule.
* `FREQ`:
  * `DAILY`: every INTERVAL-th day counted from dtstart's date. With BYDAY,
    only days whose weekday is listed.
  * `WEEKLY`: weeks start on Monday; every INTERVAL-th week counted from
    the week that contains dtstart. Within a chosen week, the days listed in
    BYDAY (default: dtstart's weekday).
  * `MONTHLY`: every INTERVAL-th month counted from dtstart's month. Within
    a chosen month: the days in BYMONTHDAY (1..31, or -1..-31 counted from
    the month's last day, -1 = last day); or, with BYDAY, the ordinal
    weekdays (`2TU` = second Tuesday, `-1FR` = last Friday; a BYDAY without
    an ordinal means every such weekday of the month); default: dtstart's
    day of month. A day that does not exist in a month (the 31st in April,
    `5MO` in a month with four Mondays) is skipped, never moved.
  * `INTERVAL` defaults to 1.
* `COUNT=n`: only the first n occurrences (counted from dtstart, before
  EXDATE removal; an excluded occurrence still uses up a count).
  `UNTIL`: the last instant allowed (inclusive), compared as an instant.
* `exdates`: an occurrence at the same instant as an exdate is removed.
* `parse_rrule` already rejects COUNT together with UNTIL; `expand` may
  assume a valid rule.
